# yourWardrobe

yourWardrobe è un'app Android per caricare e memorizzare capi e accessori, gestire il guardaroba e ricevere suggerimenti per outfit.

## Funzionalità principali
Gestione Capi: Inserimento, visualizzazione e modifica di vestiti divisi per categorie, con analisi delle immagini tramite Google ML Kit.
Outfit: Creazione, modifica e gestione degli outfit personali.
Personal Stylist: Algoritmo intelligente che suggerisce outfit basati sul guardaroba dell'utente e sulle condizioni meteo attuali (tramite OpenWeatherAPI).
Pianificazione: Possibilità di programmare outfit in vista di futuri appuntamenti.
Autenticazione: Accesso tramite email+password o "Accedi con Google" grazie a Firebase Authentication.
